# The ORC

A desktop app for running Claude Code missions: talk to one coordinator session per mission, watch it spawn worker sessions in their own git worktrees, and click into any of them.

Milestone M1 (the core) works: start a mission, talk to its coordinator, and watch workers spawn into worktrees and report back. The plan is [`docs/PLAN.md`](docs/PLAN.md), and where the build stands is [`docs/HANDOFF.md`](docs/HANDOFF.md).
